# Credo — Verified Universal Application Platform (MVP)

Run (Python 3.9+, no installs):

    python3 server.py

Open http://localhost:8787 → "Try the demo" to switch between personas
(applicant, recommenders, registrar, IE admissions reviewer, recruiter, admin).
"Reset demo data" on the sign-in page restores the seed data.

See ARCHITECTURE.md for the architecture, journeys, data model, auth approach and phases.
All organizations, people and credentials are fictional demo data; email, SSO,
identity checks and issuer signatures are simulated and labelled as such in the UI.
